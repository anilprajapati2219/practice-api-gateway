# Practice API Gateway

A Spring Boot API Gateway for the Practice Dashboard project.

## Tech Stack

- Java 17
- Spring Boot 3.x
- Spring Cloud Gateway
- JWT Authentication
- Maven

## Features

- JWT Authentication
- Role Based Authorization
- Route Configuration
- User Context Propagation
- WebClient Configuration
